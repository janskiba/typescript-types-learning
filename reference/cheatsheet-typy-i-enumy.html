Lista pułapek enumu

  • Reverse mapping działa tylko dla enumów liczbowych.
  • Enum liczbowy przyjmuje każdą liczbę — tracisz ochronę typu.
  • Enum stringowy nie przyjmuje surowego stringa.
  • const enum może zawieść przy isolatedModules i --erasableSyntaxOnly.
  • typeof Enum to typ obiektu, nie unia członków.
  • Zmiana wartości string enumu to breaking change w bazie / JSON.

API enumu — skrót

enum TaskStatus {
  Todo = 'todo',
  Done = 'done',
}

// typ unii członków
type Member = TaskStatus; // TaskStatus.Todo | TaskStatus.Done

// typ obiektu runtime
type ObjectType = typeof TaskStatus;

// wartości do iteracji
const values = Object.values(TaskStatus); // ['todo', 'done']
