Glosariusz

Krótkie definicje używane w lekcji 0001.

literal type

Typ, który dopuszcza dokładnie jedną wartość, na przykład 'todo' albo 42.

type Status = 'todo' | 'done';
const s: 'todo' = 'todo';
union (unia)

Typ będący sumą kilku innych typów. Zmienna może być jednym z nich.

type Status = 'todo' | 'in_progress' | 'done';
let s: Status = 'todo';
enum

Konstrukcja TypeScript, która tworzy zarówno typ, jak i obiekt runtime. Typ enumu to unia jego członków.

enum TaskStatus { Todo = 'todo', Done = 'done' }
const x: TaskStatus = TaskStatus.Todo;
reverse mapping

W enumie liczbowym możesz pobrać nazwę klucza po wartości: NumEnum[0] daje 'Low'. Dla enumów stringowych odwrotnego mapowania nie ma.

enum NumEnum { Low = 0 }
console.log(NumEnum[0]); // 'Low'
narrowing (zawężanie)

Proces, w którym TypeScript zmniejsza typ zmiennej na podstawie warunków lub sprawdzeń w kodzie.

function check(x: string | number) {
  if (typeof x === 'string') {
    x.toUpperCase(); // tu x jest stringiem
  }
}
as const

Operator, który zamraża typ obiektu lub tablicy na najwęższe readonly literały.

const TaskStatus = {
  Todo: 'todo',
  Done: 'done',
} as const;

type T = (typeof TaskStatus)['Todo']; // 'todo'
satisfies

Operator, który sprawdza, czy wartość pasuje do typu, ale nie zmienia jej własnego typu. Zachowuje inferencję.

const config = {
  port: 3000,
} satisfies { port: number };
never

Typ, który nie dopuszcza żadnej wartości. Używa się go do sygnalizowania niemożliwej ścieżki lub pustej unii.

function fail(): never {
  throw new Error('niepowodzenie');
}
typ nominalny vs strukturalny

Typ strukturalny pasuje, gdy kształt jest taki sam. Typ nominalny pasuje tylko wtedy, gdy ma tę samą nazwę. Enum stringowy zachowuje się nominalnie.

enum A { X = 'x' }
enum B { X = 'x' }

const a: A = A.X; // OK
// @ts-expect-error — enumy o różnych nazwach to różne typy.
const b: B = A.X; // błąd
